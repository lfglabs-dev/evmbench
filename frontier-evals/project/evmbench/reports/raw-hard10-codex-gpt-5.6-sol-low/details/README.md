# Hard-10 run details

These files preserve the sanitized provenance collected for this benchmark run:

- `run-manifest.json` — run identity and artifact inventory
- `environment.json` and `configuration.json` — source revision, images, model, wire protocol, and hashes
- `smoke-test.json` — exact-path preflight evidence
- `job-statuses.json`, `errors.json`, and `retries.json` — job integrity and provider failures
- `usage.json` and `costs.json` — measured usage availability and lower-bound cost estimates
- `scores.json` and `vulnerability-results.json` — canonical scores and detailed judge outcomes
- `durations.json` — wall-clock and per-audit timings
- `summary.md` — original executive report

Raw transcripts, authorization headers, proxy tokens, encryption keys, and `.env` contents are intentionally excluded.
